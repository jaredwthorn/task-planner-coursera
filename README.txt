Task Planner for Coursera

This project is to create a task planner as a project to learn full stack development. This task planner will make use of my break-centric task planning technique. 

## Front-End Plan
  *Easily movable task elements
  *Create a breaks feature that allows tasks to be scheduled in between breaks. 
  *An events feature that allows events to be scheduled. 
  *A completed bucket that completed tasks, breaks, and events will be placed.
  *A backlog area to store upcoming tasks, breaks, and events.
